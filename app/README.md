# Social Sparks

## Overview

Social Sparks is an Android application developed in Kotlin. The purpose of the application is to provide users with simple social suggestions based on the selected time of day.

## Features

- Time-of-day input
- Social Spark suggestions
- User-friendly interface
- Input validation and error handling
- Reset functionality

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- GitHub

## Project

This project was developed as part of the IMAD assignment.

## Version Controls

The project source code is managed using Git and hosted on GitHub.

## Testing

The application was manually tested using the Android emulator to verify the application's functionality and error handling.
